# 调研纪律与子代理使用纪律（web-intel 强化 · v1.1 · 2026-09-30）

> **来源**：长护险全面调研 F1 复盘（2026-09-28/30，read 截断致《意见》支付比例条款漏读、校验代理误判"无官方源"压过提取代理正确结论）+ **v3.0 二次偏差复盘（2026-09-30）** + DR-20260916-1（子代理 Admiralty 门禁）+ 历次调研教训（数值核验式、URL 判定坑、检索通道兜底、池路由 R8/R10.2）。
> **v1.1 新增核心结论**：**子代理偏差率与"是否有主代理提供的已核实锚定材料"高度负相关，与"是否依赖其自身从零联网检索"高度正相关**（实证见 §0）。故新增 **D7 锚定派单**为强制前置，并强化 D5 来源准入、新增 S5 条级出处。
> **适用范围**：web-intel 下所有调研（deep-research / deep-research-pipeline / anysearch 工作流），主代理与子代理均适用。本文件是调研部分纪律的**单一事实源**。

## §0 偏差实证对照（v3.0 复盘 · 为什么有了纪律仍出错）

| 子代理 | 是否有主代理锚定材料 | 工作方式 | 结果 |
|---|---|---|---|
| sensenova-researcher（v1 轮） | ✅ 有（5 份本地全文） | 读锚提取 | ✅ **正确**（报销比例 50%/70%，出处 YJ） |
| agnes-batch-runner（v3 轮） | ✅ 有（复用已交付 sub02 + curl 定向核验） | 读锚 + 定向补 | ✅ **正确**（六城数字与官方一致） |
| agnes-analyst（v3 广州深挖） | ❌ 无（要求其从零搜） | 自身联网检索 | ❌ **编造**（A/B/C/D 四级、机构 325–419 元/日、评估费 300 元、参保 951 万；把公众号链接当政策原文来源） |
| agnes-researcher（v3 国家政策） | ❌ 无 | 自身联网检索（web 工具噪声/失效） | ❌ **冲突且错**（首批 15 城混入"潍坊"、2020 新增写成"上海/厦门/青岛"、参保 1.88 亿、惠及 600 万） |

**结论**：纪律修的是"主代理怎么审"（D1–D4 已生效，本轮两次偏差均被主代理审计拦下），**没修"子代理怎么被喂"**——无锚派单等于让轻量模型凭参数记忆填空。故 v1.1 把防线前移到**派单前**。

## 一、调研纪律（防证据链断裂）

### D1 一手材料完整读取（F1 根因修复 · 强制）
- 抓取官方原文后**必须全文读入主代理上下文**，禁止依赖截断输出、摘要或子代理转述。
- **单行大文件切段**：read 工具对超长单行输出会截断（实测 `(line truncated to 2000 chars)`）。抓取后立即把单行文本按 ≤800 字符切段落盘（`_seg_*.txt`），再逐段 read 核对。
- 关键数字/条款必须**对回原文逐字核读**；"读到了截断前 2000 字符"不算读完（长护险 F1：《意见》第六（六）条支付比例 50%/70% 位于文件后半段，截断致主代理从未看到原文，终审失去裁决依据）。
- 校验子代理标"存疑/证伪"的条目，主代理**必须回读本地官方原文裁决后才能写入报告**。

### D2 存疑 ≠ 证伪；无官方源 ≠ 不存在
- 校验结论分级：`证实` / `证伪` / `存疑` / `未核验`。
- **存疑**：证据不足，先穷尽举证（≥2 通道 + 全文核读）再定性；拿不准写「未核验」附检索式与样本量。
- **证伪**：必须给出正确值 + 反向证据，不能只说"找不到"。
- 报告正文中 `存疑/未核验` 项**不得附行动建议**（AGENTS.md 铁律 8）。

### D3 矛盾产出裁决：以一手材料为准，不按默认优先级
- 多子代理产出冲突时（如提取代理读全文给出正确值、校验代理联网误判"无官方源"），**统一回读本地存档的一手官方原文裁决**。
- **不得默认"校验 > 提取"**：校验代理若未读全文，其"无官方源"结论证据链弱于读全文的提取代理——但两者都不能替代主代理亲自核读原文。
- 裁决顺序：官方原文（本地落盘）＞ 官方原文（在线直抓）＞ 权威媒体多源交叉 ＞ 行业口径（标注）。

### D4 子代理输出过同等门禁（Admiralty）
- 子代理输出**必须经过与主代理同等证据门禁**，不能因"独立执行"免检（DR-20260916-1 立规）。
- 拒收情形：推断级正面结论挂"门户首页"而非具体页面；自评置信度低（如 0.45）+ 主动报 source_alert；无方法论/无数据。
- 此类产出**只保留其负证据价值**（证明"某说法查无实据"），不采信其正面结论。
- **数值格必须写核验式**（captain 硬性要求）：表格/算式结果必须外部复算或给出来源算式，子代理/主代理自算错误自身难发现。

### D5 来源与数字纪律
- 每个城市/主题 ≥1 个官方或权威 URL；数字带来源编号 [1][2]… 文末附 URL 清单。
- 来源四档：★ 官方源（政府网/医保局/新华社/省市政府）＞ 权威媒体 ＞ 行业口径 ＞ 转引/存疑；**★D 不作依据**。
- 禁止编造 URL；查不到写「未核验」；媒体转引与官方口径必须区分标注。
- **URL 存活判定**：不用本地 PowerShell HTTP 客户端（实测代理误报 404）；用 curl 直连官方站 / anysearch extract / ego 浏览器 Bing 交叉。

### D7 锚定派单（v1.1 新增 · 防偏差前置 · 强制）
> 修的是 **派单前**，不是审单后。D1–D4 已能拦住错误入库，但代价是"错数据已产生"。本条把防线前移。

- **禁用"无锚派单"**：**不得**在未向子代理提供任何已核实锚定材料的前提下，让其"从零联网检索某主题"。轻量模型（尤其 sensenova/agnes 免费池）在无锚时会用参数记忆**填充看似合理的数字**（v3 实证：广州深挖凭空产出 A/B/C/D 四级、机构 325–419 元/日、参保 951 万）。
- **派单强制三件套**（缺一不派）：
  1. **锚定材料**：主代理已核实的原文片段/落盘路径/已知正确数字，作为子代理的基准；
  2. **许可来源域白名单**：明确"只采信 gov.cn / nhsa.gov.cn / 省市政府门户 / 新华社"等域名；
  3. **来源形态要求**：必须是**带文号/标题的政策原文或官方页面**，**禁止用公众号、搜狐、今日头条等转载链接充当政策原文来源**。
- **允许的任务形态**：①读锚提取（最稳，实证正确率最高）；②定向补漏（锚定材料 + 指定 1–3 个待补字段）；③多源交叉验证（已有候选值，让其验证而非生成）。
- **禁止的任务形态**："请调研 X 市 Y 政策并给出具体数字"（无锚、无域白名单）。
- **子代理回传硬要求**：每条数字后必须附**具体出处（文号/标题/URL）**；无出处的数字主代理一律**视为未核验**，不得入库。
- **主代理终裁不变**：即使有锚派单，D3 仍适用——子代理产出与锚冲突时以锚（一手原文）为准。

### D6 检索通道兜底链（本机实测）
- 默认：`web_search`/`web_fetch` → 不可用时按序兜底：
  1. `anysearch_cli.py`（前置 `export NO_PROXY=api.anysearch.com no_proxy=api.anysearch.com`，Windows 系统代理对 SSL 握手失败）
  2. gitbash `curl -s -L` 直连官方站点（注意 /tmp 与 Windows python 路径不一致——落盘用工作区绝对路径）
  3. ego 浏览器 Bing（`ego_status` → `ego_space_open` → `ego_navigate` → `ego_script`）
  4. agnes 子代理内置 web_search/web_fetch（R8：仅 agnes 池有）
- 抓取产物统一落盘 `deliverables/<topic>/_raw_*.txt`（UTF-8 无 BOM，显式编码）。

## 二、子代理使用纪律（与 dsh-free-pool INVOKE-RULES 对齐）

### S1 终审归口（R10.2 · 强制）
- **终审 / 裁决 / 交叉复核 = 会话模型（主代理自己做）**，不派子代理裁决。
- 校验/复核类任务派子代理做"取证与三态核验"可以，但**最终采纳/拒收由主代理依据一手材料决定**。

### S2 池路由（R8 · 联网能力差异）
- **agnes 池**：有内置 `web_search`/`web_fetch` → 可直接联网调研/校验。
- **sensenova 池**：无内置联网工具 → 只能读主代理落盘材料做结构化提取/三态判断；派单时**必须提供材料路径**，不得因"不能检索"省略检索或转派；两者皆无时须首行声明「无检索能力，结论未验证」。
- 子代理任务规范：给材料路径/子问题/期望产出/来源编号格式，回传 500-800 字紧凑 markdown。

### S5 条级出处（v1.1 新增 · 配合 D7）
- 子代理回传的**每条数字后必须紧跟具体出处**（政策文号 / 官方页面标题 / URL 三者至少一）。
- 无出处的数字 = **未核验**，主代理不得写入报告。
- 若子代理只能给"综合判断/大概"，主代理应标注「子代理推断，未核验」并另行取证，**不得**升格为事实。

### S3 分流与并发（对齐 dsh-free-pool）
- 跑量/轻量阅读/格式提取 → 免费池（sensenova/agnes）；深度推理/长文调研 → 白菜 kimi-k3（先问老板）；质证/对抗**必须跨供应商**（sensenova 三池同源只算 1 个来源，不能互查）。
- 并发：sensenova 单池 ≤20、agnes 单池 ≤6、跨池 ≤12；批任务错峰 ≥60s（agnes RPM 官方 09-23 减半后收紧）。
- 熔断：连续 3 次同类失败熔断，禁原地重试；改道（换池→换角色→主代理自做）并留痕。

### S4 派单通道
- 非 live owner 会话中 `subagent_role` 带 `run_in_background` 会报错（`session has no live agent`）→ **前台派发**（不设 run_in_background）。
- 人设完整注入（含边界纪律）；批量规则题给 1 个完整示例 + 明确总数（跨模型共性只切 2 次）。

## 三、派单模板（D7 可执行版 · 复制即用）

> 无锚 = 不派单。以下模板必须填满 `【锚】` 段才可发出。

```
## 任务：<子题名>（读锚提取 / 定向补漏 / 交叉验证 —— 三选一）
## 【锚】已核实材料（必填，缺失则不得派单）
- 落盘路径：<deliverables/xxx/_seg_yyy.txt 或 _raw_yyy.txt>
- 已知正确值：<关键数字清单，逐条列文号+条号>
- 基准结论：<主代理已裁决的结论，子代理不得推翻>
## 【白名单】只采信以下来源域（其余一律标"未核验"）
gov.cn / nhsa.gov.cn / 省市政府门户（如 gz.gov.cn）/ 新华社 / 人民日报
**禁止**用 mp.weixin.qq.com、sohu.com、toutiao.com 等转载页充当政策原文来源
## 【任务边界】
- 只做：读锚提取 / 在给定候选 URL 上定向抓取 / 对已知值做三态验证
- 不做：从零检索与数字生成；发现与锚冲突 → 给出"原文条号+具体页面 URL"并上报，**不得自行改写锚**
- 检索失败就写「未能检索到」，**不得以推断值填充**；不要求填满篇幅，未核验不扣分
## 【回传格式】
每条数字 = 数值 + 原文条号/段号 + 具体页面 URL（含路径，禁裸域名）+ 核验式
最后附：本次实际成功访问的 URL 清单（列不出 = 视为未核验）
```

## 四、收单机械门禁（v1.1 · 免人工比对的第一道闸）

子代理回传**命中以下任一指纹**，直接判「未核验」，**不进入主代理逐条比对环节**：

| 指纹 | 说明 |
|---|---|
| 来源为裸域名（`https://ybj.gz.gov.cn` 无路径） | 无法定位具体页，等于没给来源 |
| 来源为公众号/自媒体/聚合转载（mp.weixin、sohu、toutiao） | 政策类不可采信（D5） |
| 数字无文号或无条号 | 无法回原文核验（S5） |
| 自标"转引未核验""综合判断"却写入正文 | 不得升格为事实（D2/D4） |
| 给出的文号/施行日在本地一手原文中查无此值 | 直接拒收并记入偏差台账 |

命中即拦，可把「事后回读原文比对」的高成本检查，压缩为收单时的低成本过滤。

## 五、调研产出自检清单（收尾前逐项过）

- [ ] 关键官方原文已全文分段读入（非截断）
- [ ] 每个关键数字对回原文或 ≥2 独立源核读
- [ ] 校验子代理标存疑/证伪条目已由主代理回读一手材料裁决
- [ ] 矛盾产出已按 D3 裁决（不默认校验>提取）
- [ ] 子代理输出已过 Admiralty 门禁（拒收项只保留负证据）
- [ ] **派单前已执行 D7 锚定三件套**（无锚派单 = 违规，不得派单）
- [ ] 子代理回传每条数字均有具体出处（无出处视为未核验）
- [ ] 来源四档标注齐全，无编造 URL，未核验项无行动建议
- [ ] 报告含校验/审计记录附录（断言→三态→正确值→来源）
